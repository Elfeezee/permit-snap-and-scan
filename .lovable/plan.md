# Remove this Lovable conversation

- Open the conversation’s menu (⋯) in the chat sidebar, Chats page, or beside its title.
- Choose **Delete** and confirm in the deletion dialog.
- Deletion is permanent and cannot be undone. This removes the entire conversation; individual messages cannot be cleared while keeping the chat.
- If this is a project Chat mode conversation and no Delete option appears, this chat type may not support the same deletion control.
